boltforge

أداة CLI تُنشئ مشاريع Flutter كاملة بمعمارية Cubit + Repository + GetIt جاهزة للإنتاج، وتولّد Features جديدة داخل مشروع قائم بأمر واحد.

⚠ حالة المشروع الحالية

هذا التوثيق يصف Phase 1 من المشروع: الأداة نفسها، المعمارية الأساسية، نظام المصادقة (Password / OTP)، مولّد الـ Features، ومجموعة اختبارات حقيقية. لم يتم بعد تنفيذ dart analyze أو dart test فعليًا على جهاز فيه Flutter/Dart مثبّت — راجع صفحة الاختبارات لتفاصيل هذا الأمر بالضبط.

ماذا تفعل الأداة؟

عند تشغيل:

boltforge create my_app --auth=password

تقوم الأداة بالتسلسل التالي:

  1. التحقق من صحة اسم المشروع.
  2. تشغيل flutter create.
  3. إضافة الحزم المطلوبة (flutter_bloc, dio, get_it, shared_preferences) عبر flutter pub add.
  4. تطبيق المعمارية الأساسية (طبقة lib/core/).
  5. تطبيق نظام المصادقة المختار (Password أو OTP).
  6. تشغيل flutter pub get ثم flutter analyze ثم flutter test، والتوقف فورًا عند أول فشل حقيقي بدل ادّعاء النجاح.

ثم لاحقًا، داخل نفس المشروع:

cd my_app
boltforge generate offer

لإنشاء Feature كاملة (cubit + repository + model + screen) بأسلوب موحّد.

من أين أبدأ؟

  • البدء السريع — التثبيت وأول أمر تُشغّله.
  • المعمارية العامة — كيف تترابط الطبقات (Cubit, Repository, GetIt, Dio).
  • توليد Feature جديدة — الدرس الكامل المطلوب: "كيف أضيف Feature Generator جديدة؟".
